# MTS Merge

ビデオカメラ（AVCHD）で撮影した MTS ファイルを、**再エンコードなし・無劣化**で 1 つに結合する Windows 用ソフトウェアです。

## 特長

- **無劣化・高速**: MPEG-TS をバイナリ連結するため画質の劣化がなく、ディスクの読み書き速度で処理できます。
- **元ファイルを壊さない**
  - 入力ファイルは読み取り専用で開きます。
  - 出力先が入力ファイルと同じ場合（大文字小文字違い・ハードリンク等を含む）は実行しません。
  - 出力はいったん一時ファイルに書き込み、完了・サイズ検証後に正式な名前に変更します。途中でエラーやキャンセルが起きても一時ファイルは削除され、既存ファイルは変更されません。
  - 既定の出力ファイル名は「先頭ファイル名-merge.MTS」。同名ファイルがある場合は「(2)」「(3)」…と自動で採番します。
- **容量チェック**: 保存先の空き容量が足りない場合は実行しません。保存先が FAT32 の場合は 4GB 制限もチェックします。
- **かんたん操作**
  - 「追加...」ボタンでの複数選択、またはドラッグ＆ドロップ（フォルダごとドロップすると中の MTS を自動で収集）
  - 並べ替え: 一番上へ / 上へ / 下へ / 一番下へ / 名前順 / 日時順（複数選択して一括移動も可）
  - 削除 / すべて削除（リストから外すだけで、元ファイルは削除しません）
  - 合計ファイルサイズ、保存先の空き容量を常時表示
  - 進捗・転送速度・残り時間の表示、キャンセル
- **その他**
  - 188 バイト (TS) / 192 バイト (M2TS/MTS) のパケット形式を自動判別し、形式が混在している場合は実行しません。
  - 出力ファイルの日時を先頭ファイルに合わせるオプション
  - 結合中はスリープを抑止
  - exe にファイルをドロップして起動することも可能

## 動作環境

- Windows 10 / 11（x64 / ARM64）
- 配布版は .NET ランタイム同梱のため、別途インストールは不要です。

## 使い方

1. `MtsMerge.exe` を起動します。
2. 結合したい MTS ファイルを「追加...」で選択するか、ウィンドウにドラッグ＆ドロップします。
3. 並び順を確認し、必要なら並べ替えます（AVCHD は通常「名前順」で撮影順になります）。
4. 保存先フォルダとファイル名を確認して「結合開始」を押します。

## 対応形式・注意事項

- 対応拡張子: `.mts` `.m2ts` `.ts` `.m2t`
- 長時間撮影でカメラが自動分割したファイル（例: 00001.MTS, 00002.MTS …）の結合を主な用途としています。この場合、結合後は 1 本の連続した映像になります。
- **別々に撮影したクリップ同士**を結合した場合、映像自体はすべて含まれますが、クリップの境目でタイムスタンプが不連続になります。プレーヤーによっては総再生時間の表示やシークが不正確になることがあります。

## ビルド方法

[.NET 10 SDK](https://dotnet.microsoft.com/) が必要です。

```powershell
# ビルドとテスト
dotnet test MtsMerge.sln

# 配布用の単一 exe を作成
dotnet publish src/MtsMerge/MtsMerge.csproj -c Release -r win-x64 --self-contained `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true `
  -o artifacts/win-x64
```

アイコンを変更する場合は `assets/icon.png`（正方形推奨）を差し替えて、次のコマンドで `app.ico` を再生成します。

```powershell
powershell -ExecutionPolicy Bypass -File tools/make-icon.ps1 assets/icon.png src/MtsMerge/app.ico
```
